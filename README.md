# 배경 텍스트 프리젠터 (BgTextPresenter)

듀얼 모니터에 **전체 화면 배경(색상/이미지/동영상/투명) + 텍스트 문단**을 송출하는 프리젠터입니다.
배경은 별도의 송출 창(2번째 모니터 등)에 표시되고, 텍스트는 배경 위에 중앙 정렬로 올라갑니다.
이미지·동영상은 화면을 꽉 채우도록 확대·크롭(cover)되어 표시됩니다.

## 요구사항 대응

| 요구사항 | 구현 |
|---|---|
| 1. 상단 메뉴의 배경 선택 버튼 | 툴바에 색상 견본 12종 + `🎨 색상…` `🖼️ 이미지 추가…` `🎬 동영상 추가…` 버튼 |
| 1-1. 색상/이미지/동영상 배경 | 좌측 라이브러리 탭(색상/이미지/동영상) + 툴바 버튼 |
| 1-2. 여러 색/이미지/동영상 첨부 후 선택 | 라이브러리에 여러 개를 추가하고 클릭으로 전환 (설정 파일에 보관) |
| 1-4. 투명 배경 | 색상 탭/툴바의 체커보드 버튼 → 듀얼 창이 투명해져 데스크톱이 비침 |
| 1-3. 동영상 자동 반복 + 다중 선택 목록 반복 | 체크박스로 여러 개 선택 → `▶ 반복 재생`: 전체 재생 후 처음부터 다시 반복 |
| 2. 텍스트 파일 → 중앙 정렬 송출 | `파일 열기…` 후 문단을 클릭하면 배경 위 중앙에 표시 |
| 2-1. 빈 줄 문단 구분 → 선택 문단만 송출 | 빈 줄 기준 문단 분리, **문단 목록에 각 문단의 전체 내용 표시** 후 클릭한 문단만 송출 |
| 2-2. 글꼴/크기/색상/테두리/테두리 색상 | 우측 패널에서 변경 시 즉시 송출 반영 |
| 2-3. 별도 편집 모드 + 적용 시 즉시 반영 | `✏️ 편집 모드` 버튼 → 수정 → `✅ 적용` 시 송출 중이어도 즉시 반영 (파일에도 저장) |
| 3. 파워포인트 슬라이드 송출 | `📊 PPT…` 버튼으로 .pptx 등록 → 슬라이드를 이미지로 내보내 카드로 표시, 클릭하면 송출 |
| 3-1. 배경 없는(투명) PNG 오버레이 | 이미지 폴더의 투명 PNG는 배경(동영상/이미지)을 유지한 채 그 위에 겹쳐 송출 |
| 3-2. 사진 속 숨은 글(사진 노트) | 이미지 폴더의 JPG/PNG 사진에 글을 숨겨 저장 → 그 사진을 송출하면 오른쪽 노트 칸에 표시 (PPT 슬라이드 노트처럼) |
| 4. 동영상(본문) 송출 | 라이브러리에 동영상 파일 등록 → 가운데 카드의 ▶ 를 눌러야 듀얼 화면에서 재생. 소리 크기·재생 위치·자막(.srt/.smi) 선택·자막 크기 |
| 6. 🔗 묶음 (여러 종류를 한 화면에) | 왼쪽 목록에서 한 항목을 다른 항목 위에 끌어다 겹치면 텍스트·PPT·사진·동영상 카드를 한꺼번에 보고, 종류가 달라도 끌어서 순서를 섞을 수 있음 |
| 7. 🔄 새 버전 알림 | GitHub 에 새 버전이 올라오면 켤 때 업데이트 창이 뜨고, `⬇️ 지금 업데이트` 로 내려받아 바꿔 끼움 (송출 중에는 창 대신 금색 단추만) |
| 5. 음악 재생 | 상단 툴바 `🎵 음악`: mp3/aac/m4a/wav 등 여러 곡을 골라 재생 - `⏩ 연속 재생` / `1️⃣ 한 곡씩` 선택 (반복, 이전/다음, 소리 크기) |

## 실행

```bat
run.bat
```

또는 `python app.py` (Python 3.10+, PySide6, Pillow, opencv-python 필요)

파워포인트 슬라이드를 불러오려면 **파워포인트가 설치**되어 있어야 하고 `pywin32`,
그리고 슬라이드 글꼴을 원본대로 유지하기 위한 `pypdfium2`가 필요합니다.

```bat
pip install pywin32 pypdfium2
```

> **왜 pypdfium2가 필요한가**
> 파워포인트의 '슬라이드를 그림으로 내보내기'는 **파일에 포함 저장된 글꼴**
> (PC에 설치되지 않고 pptx 안에 들어 있는 글꼴)을 쓰지 않고 설치된 글꼴로 바꿔 버립니다.
> 편집 화면과 슬라이드쇼는 멀쩡한데 내보낸 그림만 글꼴이 달라지는 이유입니다.
> 그래서 이 앱은 슬라이드를 **PDF로 내보낸 뒤 그림으로 바꿉니다.**
> PDF에는 글꼴이 그대로 박히므로 원본 모양이 유지됩니다.
> 지금 보려는 슬라이드 한 장을 먼저 뽑아 즉시 송출하고, 나머지는 구간을 나눠
> 이어서 만듭니다. 구간으로 나누는 이유는 파워포인트 호출이 중간에 끊기지 않기
> 때문입니다 - 한 번에 전부 내보내면 그동안 애니메이션 모드의 슬라이드 조작이
> 통째로 밀립니다.
> 이 패키지가 없으면 예전 방식(장별 그림 내보내기)으로 동작하며, 그때는
> 상태 표시줄에 글꼴이 달라질 수 있다는 안내가 뜹니다.

## 사용법 요약

1. **배경 선택**: 툴바 색상 견본 클릭 / `이미지 추가`·`동영상 추가`로 첨부 후 좌측 탭에서 선택. 체커보드 버튼은 투명 배경(데스크톱 표시).
   - 동영상: 체크박스로 여러 개 선택 → `▶ 반복 재생` (끝나면 처음부터 반복).
2. **텍스트**: `파일 열기…` → 문단 목록에 각 문단의 **전체 내용**이 표시됩니다. 원하는 문단을 클릭하면 그 문단만 듀얼 화면 중앙에 송출됩니다.
   - 송출 중인 텍스트를 내릴 때는 `⏹ 텍스트 끄기` 버튼 또는 `ESC` 키를 씁니다.
2-1. **파워포인트**: `📊 PPT…`로 .pptx를 등록하면 슬라이드가 카드로 나열되고, 클릭한 슬라이드가 송출됩니다.
   - 첫 장이 준비되는 즉시 송출할 수 있고, 나머지는 뒤에서 계속 채워집니다.
   - 한 번 불러온 파일은 캐시(`%LOCALAPPDATA%\BgTextPresenter\ppt_cache`)에 남아 다음부터는 파워포인트를 띄우지 않고 즉시 열립니다. 파일을 수정하면 자동으로 다시 내보냅니다.
   - 슬라이드 그림은 PDF를 거쳐 만들어집니다(위 설명 참고). 포함 저장된 글꼴이 그대로 유지됩니다.
   - 슬라이드를 누르면 우측 패널이 텍스트 편집/스타일 대신 **슬라이드 노트**로 바뀝니다.
     노트는 노트 페이지의 본문만 읽습니다(쪽 번호·머리글·날짜 상자는 노트로 치지 않습니다).
     노트 칸은 옆(가운데 칸과의 경계)과 위아래(미리보기와의 경계)를 끌어 크게 볼 수 있습니다.
     미리보기는 남은 자리 안에서 송출 화면 비율대로 작아지며, 조절한 크기는 다음에 켤 때도 유지됩니다.
   - 파일을 고르면 파워포인트가 뒤에서 파일을 엽니다. 이때 파워포인트 창이 이 프로그램이나
     송출 화면 앞에 번쩍 뜨지 않도록, 여는 동안만 이 프로그램 창들을 맨 위에 올려 두고
     파워포인트가 키보드 초점을 가져가지 못하게 막습니다(열고 나면 원래대로 돌아갑니다).
2-2. **사진 속 숨은 글 (사진 노트)**: 이미지 폴더를 열면 오른쪽 칸이 PPT 처럼 **사진 노트** 칸으로 바뀝니다.
   - `✏ 숨은 글 편집` 단추(또는 사진 카드 우클릭 → `숨은 글(노트) 편집…`)로 선택한 사진에 글을 넣습니다.
     편집해도 화면에는 아무것도 나가지 않습니다.
   - 글은 사진 파일 안의 부가 정보 칸에 숨겨 저장됩니다. 그림 데이터는 한 점도 바뀌지 않으므로
     겉보기와 화질은 그대로이고, 파일을 복사하거나 USB 로 옮겨도 글이 함께 따라갑니다.
     (JPG 는 저장할 때마다 다시 압축되어 픽셀에 숨긴 글은 깨지기 때문에 이 방식을 씁니다.
     카카오톡처럼 사진을 다시 압축해 보내는 곳을 거치면 숨은 글은 지워집니다.)
   - 숨은 글이 있는 사진 카드에는 `📝` 가 붙습니다. (사진 카드에는 풍선 도움말을 띄우지 않습니다)
   - 사진 카드는 위에 그림, 아래 한 줄에 파일 이름을 그립니다. 이름이 길면 가운데를 `…`로 줄입니다.
   - 그 사진을 송출하면 오른쪽 노트 칸에 숨은 글이 나타납니다(송출 화면에는 보이지 않습니다).
   - JPG/JPEG/PNG 만 지원합니다. GIF/BMP/WEBP 등은 안내만 하고 파일을 건드리지 않습니다.
   - **ppt2jpg(PPT → JPG 내보내기 도구)로 넣은 슬라이드 노트도 읽습니다.** 그 도구는 그림 뒤에
     `PPT_NOTE_V1` + 길이 + 글 + `PPT_NOTE_END` 를 덧붙입니다. 이런 사진의 숨은 글을 여기서 고치면
     같은 방식으로 고쳐 써서, 그 도구의 [View Slide Note] 로 열어도 고친 글이 보입니다.
   - 새 판 ppt2jpg 처럼 **사진 정보(EXIF)** 에 넣은 노트도 읽습니다 — 탐색기 [속성 > 자세히 > 메모](XPComment),
     제목이 "Slide Note" 인 사진의 설명·사용자 메모. 파일 끝의 노트가 지워진 사진도 여기서 읽습니다.
     (카메라가 넣어 두는 설명 글은 노트로 보지 않습니다.) 이런 사진을 여기서 고치면 사진 정보도 함께 고칩니다.
   - 읽는 차례: 이 프로그램이 넣은 글 → 파일 끝(ppt2jpg) → 사진 정보(EXIF).
   - 사진을 송출할 때마다 노트를 파일에서 새로 읽으므로, 폴더를 연 채로 다른 프로그램에서 노트를 고쳐도 바로 보입니다.
   - 다른 프로그램이 저장하다 남긴 임시 파일(`*.tmp.jpg` 등)은 사진 목록에 넣지 않습니다.
2-4. **🔗 묶음 (여러 종류를 한 화면에)**: 왼쪽 목록에서 한 항목을 다른 항목 **가운데에 끌어다 겹치면** 묶음이 됩니다.
   (항목의 위·아래 가장자리에 놓으면 예전처럼 목록 순서만 바뀝니다. 겹칠 자리는 노란 테두리로 보입니다.)
   - 묶음을 누르면 텍스트 문단·PPT 슬라이드·이미지 폴더의 사진·동영상 카드가 한 화면에 함께 나옵니다.
     카드 왼쪽 위 표시(📄 📊 🖼 🎬)로 종류를 알 수 있습니다.
   - 카드를 끌어서 **종류가 달라도 순서를 마음대로 섞을 수 있습니다.** 섞은 순서는 곧바로 저장되고(다시 켜도 그대로),
     원본 파일(텍스트·PPT·사진)은 바뀌지 않습니다. 화면 끝으로 끌면 목록이 저절로 굴러갑니다.
   - 카드를 누르면 종류에 맞게 송출됩니다 — 글은 설정한 배경 위에 글자로, 사진·슬라이드는 그림으로(노트 칸에 사진 속 숨은 글·
     슬라이드 노트), 동영상은 재생 단추처럼 동작합니다. 오른쪽 칸도 카드 종류에 따라 글자 스타일 / 노트로 바뀝니다.
   - →/← 로 카드를 넘깁니다. 동영상 카드는 키로 넘어오면 바로 재생하지 않고, 스페이스·엔터로 재생합니다.
   - 묶음 위에 다른 항목을 또 겹치면 묶음에 더해지고, 묶음끼리 겹치면 하나로 합쳐집니다(각자 섞어 둔 순서 유지).
   - 묶음을 우클릭 → `묶음 풀기`로 원래 파일들로 되돌립니다. 묶음 파일(.bgmix)은 `%APPDATA%\BgTextPresenter\mixes` 에 저장됩니다.
   - 묶음 안의 PPT 를 아직 그림으로 만들지 않았다면 ⏳ 카드로 보이다가, 다 만들어지면 그 자리에 슬라이드들이 들어옵니다.
2-3. **🗗 노트 따로 보기**: 노트 칸(PPT 슬라이드 노트 / 사진 노트)의 `🗗 노트 따로 보기` 단추로 노트를 별도 창에 띄웁니다.
   - 이 창은 **언제나 이 프로그램 앞**에 있습니다(이 프로그램 뒤로 넘어가지 않습니다).
     다른 프로그램을 띄우면 그 프로그램이 앞에 오고, 노트 창도 이 프로그램과 함께 그 뒤로 갑니다.
   - 작업 표시줄에 나타나지 않고, 이 프로그램을 최소화하면 함께 숨었다가 다시 열면 함께 나타납니다.
   - 켜 두면 **노트가 없는 슬라이드·사진에서는 창이 저절로 숨고**, 노트가 있는 것을 송출하면 다시 뜹니다
     (공백만 있는 노트도 없는 것으로 봅니다). 꺼 두면 노트가 있어도 뜨지 않습니다.
   - 송출하는 슬라이드/사진이 바뀌면 노트도 따라 바뀝니다. `A−`/`A+`로 글자 크기를 바꿉니다.
   - 노트 창을 누른 채로 →, ←, 스페이스, PageUp/PageDown, ESC 를 눌러도 본 창에서 누른 것처럼 동작합니다.
   - 크기·위치·글자 크기는 다음에도 유지됩니다. 송출 모니터 위에 있으면(회중에게 보이므로)
     띄울 때 이 프로그램이 있는 모니터로 옮깁니다. 창의 X 를 누르거나 단추를 다시 누르면 꺼집니다.
   - **🎬 애니메이션 모드**: 이미지로 내보낸 슬라이드에는 애니메이션이 남지 않으므로,
     이 버튼을 켜면 실제 파워포인트 슬라이드쇼를 송출 모니터에 띄워 애니메이션과
     화면 전환을 그대로 재생합니다. 이때 이 창은 리모컨이 되어 방향키·슬라이드 클릭으로
     조작하며, 애니메이션은 한 단계씩 진행됩니다. ESC로 종료합니다.

2-2. **동영상(본문)**: 라이브러리 `➕ 추가 → 텍스트 / PPT / 동영상 파일…`(또는 끌어다 놓기)로 등록합니다.
   - 목록에서 눌러도 **바로 재생되지 않습니다.** 가운데 카드의 ▶ 단추(또는 `▶ 재생`, Space)를 눌러야 듀얼 화면에 나갑니다.
   - 한 번 더 누르면 일시정지, `⏹ 내리기` 또는 ESC 로 화면에서 내립니다. 다른 문단/슬라이드를 송출해도 내려갑니다.
   - 끝까지 재생되면 마지막 장면에서 멈춰 있습니다 (ESC 나 다음 항목으로 내림).
   - ← / → 키: 5초씩 이동. 재생 위치 막대로 원하는 곳으로 이동.
   - **자막**: 동영상과 같은 폴더에 이름이 같은 `.srt` / `.smi` 가 있으면 자동으로 함께 나갑니다
     (`설교.mp4` ↔ `설교.srt`, `설교.ko.smi` 도 인정). `💬 자막` 단추로 다른 파일을 고르거나 끌 수 있고,
     동영상마다 기억됩니다. 한국어 SMI 의 CP949(EUC-KR) 인코딩도 읽습니다.
   - 배경 동영상이 돌고 있었다면 재생하는 동안 잠시 멈췄다가, 내리면 이어서 재생됩니다.
   - 음악이 재생 중이면 동영상 소리가 잘 들리도록 음악을 일시정지합니다.
2-3. **음악**: 상단 툴바 `🎵 음악`의 📂 로 여러 곡을 고릅니다. 곡 이름 단추를 누르면
   목록에서 곡을 고르거나 목록에 추가/비우기를 할 수 있습니다. 목록은 저장되지만 프로그램을 켤 때 저절로 재생되지는 않습니다.
   - 재생 방식 단추(누를 때마다 바뀜, 다시 켜도 기억)
     - `⏩ 연속 재생`: 한 곡이 끝나면 다음 곡을 이어서 재생합니다. 🔁 반복을 켜면 목록 끝에서 처음으로 돌아갑니다.
     - `1️⃣ 한 곡씩`: 한 곡이 끝나면 멈추고 다음 곡을 준비만 해 둡니다(곡 이름 단추에 표시). ▶ 를 눌러야 재생됩니다.
       반복(🔂)을 켜면 그 한 곡을 되풀이합니다. 멈춰 있을 때 ⏮/⏭ 는 재생하지 않고 곡만 고릅니다.
   - 재생 단추(⏮ ▶ ⏭ ⏹)는 크게 그려져 있고, 옆에 `재생한 시간 / 곡 길이  -남은 시간`(예: `1:23 / 3:20  -1:57`)이 보입니다.
   - 음악 조작은 따로 된 도구 막대에 있습니다. 화면 폭이 1700 보다 좁으면 위 막대 아래 줄에 놓입니다.

## ESC 키 (한 단계씩 내리기)

`ESC`는 위에 얹힌 것부터 한 단계씩 내립니다.

| 상황 | 첫 번째 ESC | 두 번째 ESC |
|---|---|---|
| 동영상 배경 + 텍스트 | 텍스트만 내림 (동영상은 계속 재생) | 동영상 정지 → 투명 배경 |
| 배경색 + 텍스트 | 텍스트만 내림 | 배경색 → 투명 배경 |
| 텍스트 없이 배경/슬라이드만 | 바로 투명 배경 | — |
| 애니메이션 모드 | 슬라이드쇼 종료 → 투명 배경 | — |

투명 배경이 시작 직후의 기본 상태입니다. 저장된 배경 설정은 지워지지 않으므로, 다음에
문단을 송출하면 원래 쓰던 동영상·배경색이 다시 적용됩니다.
3. **전체 화면**: 시작하면 선택된 모니터(2개 이상이면 2번째 모니터)에 자동으로 전체 화면 송출 창이 열립니다.
4. **스타일**: 우측 패널에서 글꼴/크기/글자 색/테두리/테두리 색 변경 — 즉시 반영.
   - **세로 위치**: `위 / 가운데 / 아래` 단추로 글자를 놓을 곳을 고릅니다.
   - **위 여백 / 아래 여백** (위·아래 정렬일 때만 보이고 적용됨 - 가운데 정렬은 여백 없이 화면 한가운데): 화면 가장자리와 글자 사이의 여백(화면 높이의 %). 예) 아래 정렬 + 아래 여백 10% → 화면 아래쪽 자막 자리.
     글자가 너무 많으면 여백 안쪽에 다 들어가도록 글자 크기를 자동으로 줄입니다.
4-1. **슬라이드 카드의 ✏ / 🗑 단추**: 텍스트 슬라이드 카드 오른쪽 위 구석에 있습니다.
   - ✏ 편집: 그 슬라이드만 고칩니다. **화면에는 내보내지 않습니다** (지금 나가 있는 화면도 그대로) - 내보내려면 카드를 누릅니다.
   - 🗑 삭제: 한 번 확인한 뒤 지웁니다 (우클릭 메뉴·Delete 키도 같은 확인을 거칩니다).
   - `+` 새 슬라이드도 만들기만 하고 송출하지 않습니다. 파일에는 `💾 저장`을 눌러야 반영됩니다.
5. **편집 모드**: `✏️ 편집 모드` 켜고 문단(또는 전체 텍스트) 수정 → `✅ 적용` (송출 중에도 즉시 반영, 원본 txt에도 저장).

## 설정 저장

첨부한 이미지/동영상/사용자 색상, 텍스트 스타일, 마지막 배경·문단은
`%APPDATA%\BgTextPresenter\settings.ini`에 자동 저장되어 다음 실행 시 복원됩니다.

시작 직후의 송출 화면은 항상 **투명 배경 + 빈 텍스트**로 대기하며, 저장된 배경은
첫 문단(또는 직접 입력) 송출 시점에 적용됩니다. 시작 후 배경을 직접 고르면 그 선택이 우선합니다.

## 테스트

```bat
python test_paragraphs.py       :: 문단 분리 단위 테스트
python test_playlist.py         :: 재생목록 반복 로직 테스트
python test_media_playback.py   :: 실제 동영상 재생 반복 테스트
python test_gui_init.py         :: GUI 초기화 스모크 테스트
python test_ppt_engine_mock.py  :: PPT 엔진 로직 테스트 (파워포인트 없이 실행 - 캐시/점진적 로딩/취소 재개/대체 경로)
python test_ppt_engine.py       :: PPT 실제 내보내기 및 로딩 시간 측정 (파워포인트 필요)
python test_ppt_diag.py "파일.pptx"  :: PPT를 못 불러올 때 어느 COM 단계에서 실패하는지 진단
python test_ppt_font.py "파일.pptx"  :: 내보낸 그림의 글꼴이 원본과 다를 때 원인 진단 (포함 글꼴/설치 여부)
python test_ppt_pdf.py  "파일.pptx"  :: PDF 내보내기가 되는지, 얼마나 걸리는지 확인
python test_regressions.py      :: 회귀 테스트 (대화상자 키 입력 / 파일 저장 등록 / 실시간 송출 배경 / 배경 복원 / 긴 단어 줄바꿈)
python test_subtitles.py        :: 자막(.srt/.smi) 읽기 - 인코딩, 여러 언어 SMI, 같은 이름 자막 찾기
python test_video_music.py      :: 본문 동영상(재생 단추·자막·내리기) + 음악 목록 저장 테스트
python test_music_mode.py       :: 음악 재생 방식(연속 재생 / 한 곡씩 / 한 곡 반복) 테스트
python test_notes_resize.py     :: 슬라이드 노트 칸을 옆·위아래로 넓힐 수 있는지 (미리보기 비율 유지)
python test_image_notes.py      :: 사진 속 숨은 글 저장/읽기 (그림 그대로인지 픽셀 비교, 긴 글, EXIF, 망가진 파일)
python test_image_folder_notes.py :: 이미지 폴더의 사진 노트 칸·📝 표시·편집 시 송출 안 함
python test_notes_popup.py      :: 노트 따로 보기 창 (본 창 앞에 유지, 저절로 숨김/표시, 키로 슬라이드 넘기기)
python test_mix_bundle.py       :: 묶음 파일·카드 순서 (섞기, 원본이 바뀐 경우, PPT 준비 중 순서 보존)
python test_mix_mode.py         :: 묶음 화면 (겹쳐서 묶기, 종류별 송출, 끌어서 섞기, 키 넘기기, 묶음 풀기)
python test_updater.py         :: 새 버전 확인·내려받기·바꿔 끼우기·업데이트 창 (가짜 GitHub 서버)
python test_text_align.py       :: 글자 세로 위치(위/가운데/아래)·위아래 여백 테스트
```

실행 기록(파워포인트 애니메이션 모드에 걸린 시간 등)은
`%LOCALAPPDATA%\BgTextPresenter\logs\app.log` 에 남습니다. 느린 곳을 찾을 때 이 파일을 봅니다.

## EXE 빌드

```bat
build_exe.bat
```

결과는 **폴더**로 만들어집니다: `dist\BgTextPresenter\BgTextPresenter.exe`
(옆의 `_internal` 폴더가 꼭 함께 있어야 하므로, 옮길 때는 `BgTextPresenter` 폴더째로 옮깁니다.)

> 예전에는 exe 한 파일로 만들었는데, 그 방식은 실행할 때마다 안에 든 140MB 가까운 파일
> (Qt·동영상 코덱·OpenCV)을 임시 폴더에 풀어 놓은 뒤에야 시작해서 켜는 데 오래 걸렸습니다.
> 폴더 방식은 풀 것이 없어 바로 뜹니다. 바탕화면 바로가기는 새 exe 위치로 다시 만들어 주세요.

## 업데이트 (새 버전 알림)

exe 로 실행하면, 켜고 몇 초 뒤 GitHub **Releases** 에 새 버전이 있는지 조용히 확인합니다.
(인터넷이 없으면 아무것도 띄우지 않습니다. 상단의 `🔄 업데이트 확인` 단추로 언제든 직접 확인할 수 있습니다.)

- 새 버전이 있으면 **업데이트 창**에 바뀐 점이 나옵니다.
  - `⬇️ 지금 업데이트` → 내려받기(진행 막대) → `🔄 지금 다시 켜기` 또는 `끌 때 바꾸기`
  - `나중에` / `이 버전 건너뛰기` (건너뛴 버전은 다시 알리지 않음)
  - `프로그램을 켤 때 새 버전 확인` 체크를 끄면 자동 확인을 하지 않습니다.
- **송출 중이면 창을 띄우지 않고** 상단 단추만 금색 `🔔 새 버전 v…` 로 바뀝니다. 예배를 마친 뒤 누르면 됩니다.
- 바꿔 끼우기: 새 zip 을 `%TEMP%\BgTextPresenter_update` 에 받아 풀고, 프로그램이 꺼지면 작은 배치 파일이
  exe 폴더에 덮어쓴 뒤 다시 켭니다. 설정·묶음·라이브러리(`%APPDATA%\BgTextPresenter`)는 그대로입니다.
  실패하면 예전 버전이 그대로 켜지고 기록(`update_log.txt`)을 알려 줍니다.
- `Program Files` 처럼 쓸 수 없는 폴더에 두었으면 `🌐 내려받는 곳 열기` 로 바뀝니다 (zip 을 받아 직접 풀기).

### 새 버전 내보내기 (개발자)

1. `version.py` 의 `APP_VERSION` 숫자를 올리고 `RELEASE_NOTES` 에 바뀐 점을 적습니다.
2. 바뀐 파일들과 함께 GitHub 의 `main` 에 올립니다.
3. GitHub Actions(`.github/workflows/release.yml`)가 윈도우에서 exe 를 만들어
   `BgTextPresenter-win64.zip` 을 Releases 에 `v<버전>` 으로 올립니다 (10분 안팎).
4. 이미 설치된 프로그램은 다음에 켤 때 업데이트 창을 띄웁니다.
